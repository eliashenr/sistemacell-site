      Como nasceu

      O sistema foi criado para os funcionários agilizarem lá e eu me sentir tranquilo aqui.

      Elias, dono da CG CELL

      O Sistema Cell nasceu dentro da CG CELL, uma assistência técnica de celulares. Cada tela resolve algo que aconteceu de verdade no balcão.

      A OS esquecida esperando aprovação virou o resumo das 9h. A diferença no caixa no fim do dia virou a conferência às cegas. A peça prometida a dois clientes virou a trava de estoque.

      Não é um sistema genérico adaptado para celular. É o sistema de uma assistência, usado todos os dias numa assistência.

      Perguntas

      O que as assistências costumam perguntar.

      Preciso instalar alguma coisa?

      Não. O sistema roda no navegador do computador da loja. No celular, dá para consultar OS, vendas e relatórios.

      Funciona em computador simples?

      Sim. Em máquinas mais modestas, o sistema entra sozinho num modo leve: os efeitos param de animar e nada some da tela.

      Emite nota fiscal?

      Ainda não. Hoje o sistema imprime a OS e o cupom não fiscal. A emissão de NFC-e e NFS-e está prevista.

      Como acompanho a loja de longe?

      Pelo Telegram, com um aviso a cada OS aberta e um resumo às 9h das OS paradas. No sistema, a auditoria e o ponto mostram o que a equipe fez.

      Meus dados ficam seguros?

      Ficam num banco de dados gerenciado na nuvem, com conexão criptografada. Você baixa um backup completo quando quiser, e cada acesso fica registrado.

      E se a internet da loja cair?

      O sistema precisa de internet. Se a conexão da loja cair, dá para continuar usando pelo roteador do celular até ela voltar.
